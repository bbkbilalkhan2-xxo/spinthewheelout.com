# 🎡 SpinTheWheelOut — Free Random Wheel Spinner

[![SpinTheWheelOut Screenshot](screenshot.jpg)](https://spinthewheelout.com/)

**[SpinTheWheelOut.com](https://spinthewheelout.com/)** is a free, customizable online spinning wheel for instant decisions, giveaways, raffles, and classroom games—no account or login required.

👉 **Live Website:** [https://spinthewheelout.com/](https://spinthewheelout.com/)

---

## ✨ Key Features

- **Up to 1,000 Entries:** Add or bulk-import up to 1,000 custom choices or names with zero lag.
- **100% Private:** All calculations run locally in your browser session with zero server-side tracking.
- **Fair & Unbiased:** Uses the browser's hardware-backed Web Cryptography API (`crypto.getRandomValues()`).
- **Quick Presets:** Built-in presets for Food, Yes/No, Truth/Dare, Teams, and Giveaways.
- **Creator & Classroom Ready:** Supports OBS overlays, embed codes, sound toggles, and shareable wheel URLs.

## 🔗 Specialized Tools

- **[Spin the Wheel Hub](https://spinthewheelout.com/spin-the-wheel/)** — All-in-one customizable online wheel spinner.
- **[Wheel of Names](https://spinthewheelout.com/wheel-of-names/)** — Random name picker with winner elimination for teachers and teams.
- **[Giveaway Wheel](https://spinthewheelout.com/giveaway-wheel/)** — Live raffle and contest winner picker for streamers and events.
