SpinTheWheelOut — Developer & Streamer Guide

SpinTheWheelOut is a browser-based random picker wheel built for unbiased giveaways, classroom selections, and instant decision-making without logins or server-side tracking.

1. Cryptographic Fairness Architecture

Standard JavaScript spinners rely on Math.random(), which uses a pseudo-random number generator (PRNG) susceptible to seed predictability. SpinTheWheelOut uses the browser's hardware-backed Web Cryptography API:

const array = new Uint32Array(1);
window.crypto.getRandomValues(array);

This ensures every wheel slice maintains an exact, uniform mathematical probability across up to 1,000 custom entries.

2. Specialized Picker Modes

  • Classroom & Raffle Draws: Use the Wheel of Names mode with automatic winner elimination to prevent duplicate picks.
  • Stream Overlays: Add the spinner directly to OBS Studio or Streamlabs as a Browser Source for live Twitch and YouTube giveaways.
  • Zero Data Collection: All entries and spin histories stay 100% inside local browser memory (FERPA & COPPA friendly).
